# Braun for Diamond Bar

Official campaign website for Michael Braun, candidate for Walnut Valley Water District, Division 2.

**Live website:** [braunfordiamondbar.com](https://braunfordiamondbar.com)

## About this repository

This repository contains the production files for the Braun for Diamond Bar campaign website. It is a static website built with HTML, CSS, and JavaScript.

The site intentionally does not use WordPress, PHP, plugins, or a database.

## Site structure

* `index.html` — Main campaign page
* `404.html` — Page-not-found response
* `assets/css/` — Website styling
* `assets/docs/` — Campaign literature
* `assets/images/` — Campaign images and graphics
* `assets/js/` — Navigation and interface scripts
* `assets/videos/` — Campaign video clips
* `_headers` — Security and caching headers
* `robots.txt` — Search-engine instructions
* `sitemap.xml` — Search-engine sitemap

## Deployment

Changes pushed to the production branch are automatically deployed through Cloudflare.

Manual changes made directly in Cloudflare may be replaced by the next GitHub deployment, so this repository should remain the authoritative copy of the website.
